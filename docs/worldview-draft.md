## 一句话概念

世界是乐神唱出的一首歌。每个纪元末，歌声像回声一样衰减——「静默」降临，世界重开。玩家是唯一不被静默影响的人，要在纪元的最后十年，把这首歌重新唱下去。

## 精神主题（已定）

**C 为主、B 为骨**：记忆与传承是魂——世界会消失，但人们留下的声音不会真正消失；自由与选择是骨——命轮砸不砸、这一生怎么过，由人自己选。A 希望与重生作为结局的画面，D 生存与牺牲作为局部剧情的质地，都往这个骨架上挂。一句话版：**即使知道世界终将沉默，人们为什么仍然愿意发出声音。**

## 创世神话（提案）

- **乐神**以歌创世，所唱之歌暂名「长歌」；唱罢沉睡，世界靠回声自行运转。沉睡前，长歌在若干地点留下「试炼残响」——没有意志、只按歌的规则运转的考验机关（乐神试炼的主持者，见"核心成长循环"）。
- 一首歌不能只有一个声音：每个纪元，世间的生灵都在无意中"接唱"——说话、敲钟、唱歌、刻碑，一切发声都是在替世界续命。
- 当一个纪元的人们渐渐不再发声、不再记得旋律，歌声衰减，**静默**随之而来。
- **命轮（已定，核心悬念）**：乐神沉睡前留下的重开机制。它不是诅咒的源头，而是一台"收声、再唱"的机器——归零时收走世间回声，再用回声把世界重新唱出来（详见"归零规则"节）。绝弦者想砸碎它：砸碎之后，世界要么挣脱轮回、真正新生，要么**再也不会醒来**。哪种是真，留作主线最大悬念，前期不揭晓。

## 声音的三层（已定）

- **声音**：一切有主的持续发声（说话、敲钟、唱歌）——维持局部世界，把静默顶在门外。普通人敲钟能守城，靠的就是这一层。
- **共鸣**：声音与世界、与回声相连的行为——唤醒遗迹、顶开静默深区，以及与历代英雄的回声相连（抽卡）。是玩家改变世界的手段。
- **纯正音符**：创世之歌散落的原声——唯一能永久强化余音之子的力量（来源已定：原曲散落说）。
- **新声的位置（主题处理）**："新声能续世"（变调纪元的证明）走的是上面两层——声音与共鸣产出经济、事件与世界变化；纯正音符只承担"永久强化"。这是刻意的分工：旧歌决定你有多强，新声决定世界还能走多远。

## 纪元编年史（提案）

| 纪元 | 名 | 一句话 |
| --- | --- | --- |
| 第一纪元 | 初鸣 | 乐神亲唱，巨人行于大地，山川都是歌词 |
| 第二纪元 | 合声 | 万族学会唱歌，文明巅峰；因有人想改写歌词而终结 |
| 第三纪元 | 独奏 | 一位皇帝独占了歌声，天下只许一种声音，纪元在沉默中干枯 |
| 第四纪元 | 变调 | 有人第一次在歌里唱出"不属于原曲的音"，世界没有惩罚他——世人第一次知道，原曲之外的新声同样能续世（注：纯正音符出自原曲散落，与此无关，来源口径已定） |
| 第五纪元 | 失聪 | 人们造了太多噪音，听不见彼此，静默来得最快 |
| 第六纪元 | 残响 | **当前纪元**。游戏发生在其最后十年 |

六纪元是连续因果（已定）：合声的众声喧哗催生独奏的垄断（人人都想改歌，不如只许一个声音），独奏的垄断催生变调的反抗，变调的自由泛滥成失聪的噪音——前一纪元的解法总是后一纪元的病根。每个纪元都在大陆上留下回声遗迹——上一纪元的城、没唱完的歌、没送到的信，都是可探索内容。

## 静默的规则（提案，玩法相关）

静默分五阶，从大陆边缘向内陆推进：

1. **失声** — 声音变小，远处的人喊话听不见。
2. **失色** — 颜色褪去，世界开始发灰。
3. **失名** — 人忘记名字，先忘别人的，再忘自己的。
4. **失史** — 书籍空白、碑文脱落，历史出现断层。
5. **归零** — 一切实体消散，只有**回声**被命轮收走，带进下一纪元（详见"归零规则"节）。

- 一切**持续的、有主的声音**能把静默局部顶回去：钟声、歌声、朗读声。这就是守钟者守钟、铭声者刻碑时要出声朗读的原因——他们不是在搞仪式，是在打仗。
- 静默浓度也不只看离边缘的远近：**原声锚点**（残碑、大钟、万声碑这类凝固了大量原声的物件）周围，静默会被压淡。灰烬原野地处大陆腹地、又有残碑为锚，是全大陆静默最淡之处——余音之子每个纪元都醒在那里，正因为那里最稳；它的北缘灰线之外，静默才陡然变浓。
- 在失名阶以上的区域停留太久的人，会变成**失声者**：被静默收编，替它猎杀"声音太大的存在"。失声者分三层（已定）：**无我**（只剩猎杀本能）/ **残忆**（保留生前习惯与碎片记忆）/ **清醒**（记得自己是谁，却控制不了自己）。失声者可来自任何阵营——守钟者、铭声者、绝弦者皆可，因此每个重要的失声者都曾是一个具体的人。失声者还有第二种来源：遗迹中滞留的**回声**被静默污染、凝结成形——这类"回声失声者"没有本体，是某个纪元的声音残影（灰烬原野半埋之城的教学怪即属此类）。
- 余音之子每通过一次乐神试炼，歌声更响——能顶开更深的静默区，也会被更强的失声者盯上。（与 Ryan 定的"试炼提升静默威胁"咬合，威胁规则见"核心成长循环"。）

## 归零规则（已定：方案乙——只有回声能过纪元）

- **清掉什么**：纪元末归零时，一切实体——山川、城市、物件、活人——全部消散，没有任何物质能直接过纪元。
- **留下什么**：只有**回声**。命轮收走散佚的回声，在下一纪元把世界**重新唱出来**：地貌因回声古老而大体重复；城与物只有被足够多的人记住、唱过、刻过、回声够响，才会被重新唱回——而回声会衰减、失真，所以归来的遗迹总是残缺的（半埋之城就是第五纪元那座城的回声在本纪元凝固的样子：半截、错位、只剩喊声；掉进城里的钟舌同理，是上纪元那口钟的钟舌回声）。
- **活人怎么"过"纪元**：没人能以肉身过纪元。余音之子是被命轮与残碑锚定的最强回声——每个纪元在残碑旁最先凝固成形，带着全部记忆醒来；阿迟同理以回声过纪元（他的回声为何不散 = 机密，见待定清单）。守碑人则是每个纪元的新人，靠《守碑录》接力——那本书是回声凝固之物，被一代代朗读接唱，才不散。
- **阵营逻辑因此成立**：铭声者刻碑朗读，是把文明的声音唱得够响，好让它在下纪元被重新唱出；守钟者敲钟，是不让自己城的回声在归零前散掉；绝弦者要砸的命轮，正是这台"收声、再唱"的机器。
- **推论（已定）**：被足够响亮地传唱的假话，也可能在下纪元被当作真事唱回来——贾史卖的假历史因此不只是骗局，是在篡改未来纪元的"事实"。

## 玩家（已定 + 提案）

- **称号：「余音之子」**（已定）：世界之歌正在消失，他是最后不灭的那段余音。
- 不被静默影响：声音、名字、记忆都不会被**夺走**——类似救世主的位置。（区分：静默对声音**传播**的物理压制对所有人一视同仁——在失声阶里他喊话一样传不远、也听不见自己的脚步声；他只是不会被吃掉声音、忘记名字。）
- 每个纪元都在灰烬原野醒来，身边残碑刻满历代自己的笔迹，最新一行："这一次，别再迟到。"
- **"迟到"之谜（真相已定，主线核心悬念）**：真相 = **历代余音之子的主动选择**——每一代都在关键时刻主动放弃了"及时赶去阻止静默"，转而去保住某样东西。残碑上的"别再迟到"，是历代在付出代价之后留给自己的自责与警告。世间流传的另两说（醒来时间不定 / 命轮机制限制）是世人、也是玩家前期的认知，不是真相。**历代保住的到底是什么 = 主线第二层悬念，暂不揭晓**，主线设计阶段再定，且必须与命轮、送信人之谜互相咬合。
- 在共鸣池中属于 **普通五星**（见共鸣系统）。

## 阵营（改名已定；人物为提案）

| 旧名 | 新名 | 主张 |
| --- | --- | --- |
| 记录者 | 铭声者 | 把整个文明的声音刻上「万声碑」，送进下个纪元 |
| 终结派 | 绝弦者 | 轮回才是诅咒：亲手弹断最后一根弦，让世界真正死去或真正新生 |
| 守夜人 | 守钟者 | 不管纪元，只守城里最后一口钟——钟声还在，城就还活着 |
| （敌对）静默 | 失声者 | 被静默吞掉名字与声音的人，如今替静默猎杀"声音太大的存在" |

**守誓者**（统称，非组织）：末世里立誓要完成一件事的人——守一座城、送一封信、等一个不会回来的人。三大阵营之外，大陆上最动人的故事多在他们身上。**群像（提案示例）**：老守钟人（失聪，靠掌心数节拍；正式名单中名「洪钟」，见首发角色名单）、刻碑的少女（铭声者；名单中名「孟回」）、绝弦者首领（曾是守钟者，亲手停过一座城的钟，坚信"有尊严的结束"好过"无尽的重开"）、送信人（名单中名「阿迟」，送一封写了九百年的信；收信人是谁，他从不说）。

## 日常生活与习俗（提案，世界要"活"）

- 每座城的钟楼挂着**末日倒计时**，但日子照过：集市、学堂、婚事，一样不少。
- 人一生有**两个名字**：一个日常用，一个出生时刻在家族小碑上——防失名，忘了日常名，碑上的还在。
- **婚礼在钟下举行**：借钟声作证，静默夺不走被钟声"盖过章"的誓言。
- **葬礼要唱着送**：哭声会被静默吃掉，歌声不会——所以这片大陆的葬歌特别好听。

## 核心成长循环（Ryan 定）

- 探索大世界 / 主线 / 支线 → 获得 **纯正音符**（来源已定：创世之歌散落的原声，未被静默污染者方称"纯正"；用于提升自身能力）、弦币、升级材料（各地区专属掉落）。
- 活动积累经验升级；**每 10 级**须通过 **乐神试炼** 才能提升等级上限。
- 通过试炼的收益：获得奖励、解锁下一章主线。
- 通过试炼的代价：玩家的"歌声"更响 → **静默阵营（失声者）威胁同步提升**。威胁规则（已定）：威胁等级**封顶**，且与主线乐章进度绑定，不随等级无限涨；每次试炼后开放地区"压静默"事件（修钟塔、重刻碑），可局部削弱静默；威胁提升带来新敌人 / 新事件 / 新奖励，不只是数值膨胀；不剥夺已解锁的探索便利——避免"升级＝惩罚"。

## 共鸣系统（抽卡，Ryan 定）

- **单机游戏，没有限定池**——所有角色常驻，不搞限时绝版。
- **稀有度分层**：普通五星（如余音之子本身）/ 地区五星 / 普通四星 / 地区四星。
- **入池时序（修补）**：角色在主线中正式登场后才进池——普通池亦然（如阿迟在序章末登场后入池，阿忘在正式入队章节后入池），与地区池"先剧情、后共鸣"的逻辑一致，不会出现"还没见过就先抽到"。
- **共鸣的解释（修补）**：共鸣唤回的是一个人"声音的回声"：历代人物是其遗声，当代活人是其此刻之声在世界中的回响——本人仍在原地生活，入队的是有其记忆与性情的回声；乐魂即同一个人的多段回声叠合。这是当代活人可以被共鸣、叠乐魂的原因。
- **乐魂**（口径已定）：抽到重复角色 → 增加该角色乐魂；**含本体共 7 份封顶**（本体 + 6 个乐魂），类似原神命座；四星角色同样适用。
- **专武**：每个五星角色有自己的专属武器；四星角色没有专武。获取方式：**独立专武池**（已定），且专武池同样分 **普通 / 地区**（已定）——地区五星的专武归该地区的专武池。
- **地区池规则**（已定）：地区角色池与地区专武池，须 **完成该地区主线剧情** 后解锁，且必须 **身处该地区** 才能进行共鸣。
- **满乐魂溢出**（已定）：角色满乐魂后再抽到重复，自动转化为 **回声碎片**（五星给得多、四星给得少）。回声碎片用途（已定）：碎片商店兑换清单 = **角色专武 / 突破材料 / 皮肤**（Ryan 定；不兑换抽卡货币）。其中突破材料为**限量补缺**定位：主来源仍是地区探索掉落，碎片商店只负责差一点时补齐，避免成长必需品被压在重复抽卡上。
- **专武重复**（已定）：专武池抽到重复专武 → 精炼提升（类似原神精炼，上限暂记 5 阶，数值阶段再定）；精炼满后的溢出同样转回声碎片。
- **皮肤**：角色外观收集品，通过碎片商店兑换（已定此获取途径；是否还有其他途径待定）。

## 货币

- **弦币**（已定名）：通用代币，探索 / 支线 / 出售材料获得；用于商店购物、升级与突破的手续费。
- **始鸣晶**（已定名）：高级代币，类似原神的原石——世界初鸣之声凝结成的晶体；主线 / 乐神试炼 / 成就 / 探索产出；可兑换共鸣结晶（兑换率提案 160:1，数值阶段可改）。**已定：不可购买**，没有任何付费入口，纯玩法产出。
- **共鸣结晶**：共鸣专用货币，角色池与专武池通用，1 枚 = 1 抽；主要由始鸣晶兑换得来。
- **纯正音符**：成长资源（非货币），只用于提升能力（已定）。
- **地区材料**：各地区专属掉落，用于升级 / 突破（已定）。

## 地区规划（长期运营：主线以「乐章」为单位更新，一乐章一新地区）

首发五区（风貌与材料为提案）。**地区原则（已定）：每个地区都有内部反对声，不做阵营主题展馆**——如碑林高原也有想删掉自己过去的人、以伪造历史为生的商人：

1. **灰烬原野** — 醒来之地，新手区，静默最淡。专属材料：「烬土」。（已细化，见"地区细化 · 灰烬原野"）
2. **鸣钟原野 · 钟城** — 守钟者主场，城里有 108 口钟。专属材料：「钟铜」。
3. **碑林高原** — 铭声者主场，万声碑所在。专属材料：「铭石」。
4. **断弦峡谷** — 绝弦者盘踞之地，峡谷里全是被弹断的巨弦残骸。专属材料：「断弦丝」。
5. **无声之境** — 静默前线（失名阶以上），高难区，首发只开放边缘。专属材料：「静默结晶」。

后续版本储备：海底沉城（沉没的歌剧院）、天穹回廊、地下共鸣窟、歌源之地（命轮所在，终局地区）。

## 运营与开发原则（已定）

- **运营**：本地存档、离线可玩、不依赖每日登录、无错过即绝版的内容——与"单机无限限定"的决定一致；长期运营靠版本更新（新乐章 = 新地区 + 新主线），不靠在线服务绑架。
- **存档修改彩蛋（已定）**：本地存档做完整性检测；检测到被修改时**不拦截、不惩罚、不回滚**，只在商店里悄悄多出一个小彩蛋：玩家拿着来源可疑的始鸣晶消费时，老板不戳破、不拒绝，只幽幽说一句（台词已定，Ryan 原话）：**"既然系统认为你的始鸣晶是真的，那我也姑且认为它是真的吧。。。"**态度：单机游戏，改存档是玩家的自由，但这个世界会"记得"你动过手——正合主题 C。注：本地检测本就绕得过去，无所谓，彩蛋不是防线，是玩笑。
- **终局与收尾（已定）**："最后十年"的倒计时是**叙事时钟**——随主线乐章推进，而非真实时间流逝，不催玩家。终局乐章（歌源之地）完成抉择后，世界进入**终章世界**：抉择的结果会改变世界状态（灰线位置、各城命运、NPC 去向），游戏不删档、不重置；后续乐章继续讲终章之后的故事（各地的余波、新纪元的序章），长期运营在终局之后依然成立。
- **开发分期**（世界观五区不变，只排开发顺序）：原型 = 灰烬原野（验证移动 / 战斗 / 探索）→ 首发三区（+ 鸣钟原野、碑林高原，完成核心体验与主线）→ 后续更新（断弦峡谷、无声之境）。

## 首发角色名单（提案；入池标准为 Ryan 定调）

**入池标准（已定）**：没有意义的 NPC 不做四星。一个角色能入池（可共鸣、可养成），必须至少占一条：① 有自己的故事线 / 抉择，而不只是一个职业或一个梗；② 与主线、阵营冲突或核心悬念直接相连；③ 玩家会真心想把他放进队伍。不满足者降为普通 NPC——照样活在世界里、演剧情、发任务，只是不入池、不占养成与抽卡资源。

**名单结构**：角色来源分两类——当代人（活在第六纪元）与**历代回声**（往纪元人物的回声，共鸣唤回的正是他们），这是普通池能跨地区的原因。**余音之子本体**主线开局即获得；普通池里抽到的他是其历代回声，转化为他的乐魂。定位（输出/辅助等）只暂记气质，战斗系统未设计，不写死。

## 地区细化 · 灰烬原野（提案）

> 首发第一区 / 原型区（验证移动、战斗、探索）。静默浓度：全大陆最淡，仅**失声阶**边缘。专属材料：**烬土**。

**一句话印象**：每个纪元都在同一块灰里醒来——而灰里有一座村子，世世代代等他醒来。

### 子区域（2D 地图分区）

1. **残碑原** — 醒来之地。半人高的残碑插在灰原中央，碑上是历代自己的笔迹；风过时碑身会发出极低的嗡鸣——它在"哼"历代的事。教学起点。
2. **守碑村** — 第一个聚落（见"人"）。几十户人家，村口一口裂了的钟，村中一口井，几亩靠烬土种活的灰麦田。
3. **灰麦田与风蚀坡** — 安全采集区：烬土、灰麦、风蚀石。教采集与地形高低差。
4. **半埋之城** — 第五纪元（失聪纪元）的一座小城，半截沉在灰里。教学遗迹：主线纯正音符、第一场战斗都在这里。城里的回声很吵——失聪纪元的人到死都在喊话，喊声留到了今天。
5. **旧驿道** — 通往鸣钟原野的古道，驿站早塌了，路牌还立着。阿迟在这里登场。
6. **灰线** — 原野北缘，静默的边线：站在这里喊话，声音传不出十步。只作展示与封锁——线的那头是通往无声之境的方向，高等级回访内容，首发不开放。

### 人

- **守碑人** — 不是一个人，是一个村：守碑村的村民自称守碑人。每个纪元，世界重开之后，总有一家人先在碑旁醒来、搭屋、种田，等余音之子睁眼。他们不记得前代的事，但留下一本**《守碑录》**：每个纪元的第一页都是同一句话——"他醒了，比上次早/晚。"（由每代的守碑人接力写。）
- **村长婆婆** — 本代守碑人的头。她翻开《守碑录》给玩家看：玩家不认识这个村子，这个村子却认识他——这是全游戏第一个"C 主题"时刻：**被等待，就是被记住。**
- **阿迟（送信人）** — 序章末在旧驿道相遇。他九百年都在这条路上走，见余音之子醒来，只说一句："这封信，是写给一个迟到的人的——但还不能拆。"然后继续赶路。（普通池解锁的剧情锚点；收信人身份不在序章明牌。）
- **阿忘** — 半埋之城边缘出没：她循着玩家战斗的声音找来，远远跟着，不敢靠近。序章只露面，不入队——入队在后续主线。
- **拾声** — 在半埋之城门口摆摊的拾荒者（NPC）：游戏内第一个"回声买卖"入口，教玩家回声也是物资。

### 序章主线节拍

1. **醒** — 灰原、残碑、"别再迟到"。玩家读碑，第一次共鸣：碑里唤回的，是**上一个自己的回声**（共鸣系统教学，且第一个共鸣对象是"自己"，扣紧历代主题）。
2. **村** — 守碑村、《守碑录》、裂钟。村子请他帮忙：村口大钟的钟舌在上个纪元末掉进了半埋之城——没有钟，村子在静默面前是裸的。
3. **城** — 进半埋之城取钟舌：采集、解谜（循回声找路）、首战**无我失声者**（回声凝成型——这座城当年的喊声被静默凝成了它）。在城心找到主线那枚**纯正音符**（本区共 3 枚，另 2 枚在探索里，见下）。
4. **鸣** — 回村装钟、敲响：钟声荡开灰原，灰线肉眼可见地退后了几步——玩家第一次亲手"压静默"，也是守钟者主题的预演。
5. **路** — 旧驿道遇阿迟；远处传来钟城的钟声（108 口钟的和声第一次响起），序章结束，鸣钟原野开放。

### 纯正音符分布（本区共 3 枚）

- **主线 ×1**：半埋之城城心，序章必得（见上）。
- **探索 ×2（Ryan 定：探索获得，与剧情无关，可漏、不限时）**：
  1. **灰线界碑之后** — 北缘灰线边上有一块历代守碑人立的界碑，音符嵌在碑背面：要踏进失声阶半步才够得着。本区静默最淡，踏进去只是听不见自己的脚步声——用最小的代价教玩家"静默边缘有宝贝"。界碑本身是历代守碑人立的**锚**，位置不随灰线进退：序章敲钟后灰线退后，这枚音符依旧藏在碑背的"碑影"里——那片地方永远比外面静一层，拿它的代价不随主线消失。
  2. **风蚀坡鸣石群** — 坡上有一群被风吹出孔洞的鸣石，风起时呜呜作响；最大的一块鸣石石心里嵌着音符，循声找过去就能发现——教"循声探索"：声音越完整的地方，越可能有原声留下来。
- 探索音符是给愿意逛地图的人的奖励：不挡主线、不进图鉴压力（图鉴只记总数），错过可随时回访补拿。

### 支线（提案，2 条）

- **《没有收信人的遗书》**：半埋之城里找到一封第五纪元的遗书，收信人姓氏还在守碑村里活着——送过去，还是不送？（传承主题的小型版。）
- **《拾声的价目表》**：帮拾声从城里捡回三段"值钱的回声"，最后一段是他自己死去同伴的声音——他忽然不卖 了。（NPC 也要有自己的选择，呼应入池标准。）

### 敌人与生态

- **无我失声者**（教学怪）：半埋之城的喊声回声被静默凝成的残影（回声失声者），只会对声音扑过去——教玩家"你的声音既是武器，也是靶子"。
- **灰原听兽**：原野的野兽，耳已退化，靠地面震动捕猎——静默地带连生态都改了。这里的猎人打猎从不说话，用脚步交流。

### 声音生态

风过灰原的呜声、残碑的低鸣、村里的鸡鸣与灰麦田的镰刀声、裂钟哑掉之后的空缺——序章敲响大钟时，玩家会第一次听见这片土地"完整"的声音。这个前后对比，是全游戏的声音设计标尺。

### 与其他地区的连接

- 南 · 旧驿道 → **鸣钟原野**（序章末开放）
- 北 · 灰线 → 无声之境方向（封锁，高等级回访）
- 半埋之城深处有一口**竖井**，通向地下——地下共鸣窟的入口之一，首发只露洞口，不开放

## 地区细化 · 鸣钟原野 · 钟城（提案）

> 首发第二区。推荐等级带 Lv.11–20（本章主线完成后开放第二次乐神试炼的衔接）。静默浓度：城内全大陆最稳（钟声锚点密集），城北无钟谷一带达**失色阶**边缘。专属材料：**钟铜**。

**一句话印象**：一座靠钟声活着的城——钟声覆盖之处是"白天"，钟声到不了的地方，世界正在悄悄褪色。而守这座城的两个人，一个聋，一个哑。

### 子区域（2D 地图分区）

1. **钟城主城** — 一百零八口钟分布全城钟楼，每日齐鸣三次，钟声覆盖之处静默退后一里。城门规矩：新来者要在门钟下站满一炷香，"让钟声认人"。
2. **铸钟坊** — 哑铸的工坊。铸钟、修钟、试音都在这里；坊里有一面"试音壁"，新钟先对着壁敲，壁会把声音还回来。
3. **钟塔群与守钟人宿舍** — 守钟者的驻地。一百零八个岗位，九百年从未缺过一次班——这句话是钟城的骄傲，也是钟城的病。
4. **城北无钟谷** — 两山之间的一道哑谷，地形吃声，钟声传不进去。谷里静得发慌，颜色比城里淡一层——失色阶的预演区。年轻人偷偷去那里"透气"。
5. **钟铜原** — 城外原野，钟铜矿与风原。采钟铜的地方，也是钟鸟的栖息地：这种鸟学钟声学得惟妙惟肖，常有新守钟人对着鸟练敲。

### 人

- **洪钟（五星，地区池）** — 守钟人首领，聋了。他听不见钟声，靠脚底和掌心读地面的震动判断一百零八口钟的状态，九十年没误判过一次。全城最"静默"的人，是全城最稳的锚——他的存在本身就是对静默的反驳：守钟靠的不是耳朵，是不缺席。
- **钟玲（NPC）** — 洪钟的学徒，能在齐鸣里听出哪一口钟"不对"。她是洪钟的耳朵，洪钟是她的底气：老聋少敏，两个人合起来才是一个完整的守钟人。
- **哑铸（NPC）** — 铸钟匠，天生不能言。他铸的钟他自己一口都没听过，却口口是好钟——验收全靠把手贴在钟身上读震。城里人说：哑铸的钟替他说话，一说就是几百年。
- **闻寂（新 NPC，本区内部反对声的人格化）** — 年轻守钟人，夜班时偷偷溜去无钟谷坐着。他问的问题不是反派问题，是全章的题眼："钟声是为了让我们活下去，还是我们活下去只是为了敲钟？——你们有没有人，真的听过安静？"他的身边正在聚起一小群年轻人；绝弦者的招募者，也远远地看着他们。

### 本章主线节拍

1. **到** — 沿旧驿道抵达钟城，赶上正午齐鸣：一百零八口钟的声浪把灰原的残响一扫而空。序章结尾听到的"远处和声"在这里兑现。入城先过门钟"认人"。
2. **缺** — 钟玲在齐鸣里听出第七十三号钟走音了。守钟人官方不认：钟走音 = 静默蚀城，承认了，九百年没缺过班的招牌就砸了。走音钟辖区的那条街，已经开始有人说话没声儿——失声阶在城里探了头。
3. **查** — 跟钟玲爬塔验钟：钟身内侧有静默蚀纹，像字被擦淡。结论：这口钟不是修得好的，得重铸。洪钟九十年第一次误判——不，他判对了钟的震，却瞒了：他早就知道，只是怕城先乱。这位老人的"守"，第一次露出代价。
4. **问** — 重铸期间那条街的声音一天比一天小，闻寂们的夜聚却一天比一天热闹：有人开始说，安静也没什么不好。玩家可陪闻寂去一次无钟谷（支线《闻寂的夜行》），听他把话说完——他不是要毁城，他是想知道城墙之外的世界是不是真的只剩死。绝弦者的招募者在谷口出现过一次，不说话，只留下一截断弦。
5. **鸣** — 新钟铸成（哑铸收尾，钟舌用的是序章那口裂钟的钟舌回声——灰烬原野的东西在这里派上用场），玩家与洪钟、钟玲一起敲响新钟：齐鸣补全，那条街的声音哗地回来。闻寂站在人群最后，听完，说："……原来满城的钟声，是这个意思。"他没认错，也没走——他把夜班表上自己的名字，又往后排了一页。本章结束，**鸣钟原野地区池开放**（余音之子须身在钟城共鸣）；东行去碑林高原的路开。

### 纯正音符分布（本区共 4 枚，提案）

- **主线 ×1**：重铸新钟的钟心——铸钟时以回声为模，音符是哑铸"听"不见却铸得出的那一声，鸣节拍必得。
- **探索 ×3（与剧情无关，可漏、不限时）**：分布在本区声音的三个极端——
  1. **静极**：无钟谷最深处，绝对安静的谷心岩壁后。静默最浓的地方反而藏着原声——拿它时四周一点声音都没有，只有自己的心跳。
  2. **哑处**：铸钟坊试音壁后有一口从未响过的哑钟，音符封在钟腹里：敲它不响，得用共鸣"听"进去。
  3. **响极**：最高钟塔的塔顶钟心，只在三日齐鸣的瞬间够得着——声音最大的地方藏着声音，全城最响时反而没人听得见它。

### 支线（提案，2 条）

- **《哑铸的第一口钟》**：哑铸年轻时铸的第一口钟还挂在城外小村，人已迁走，钟还在自鸣。陪他去看：他把手贴在钟身上，站了很久——他这辈子第一次"听"自己的钟。
- **《闻寂的夜行》**：陪闻寂夜入无钟谷。他在谷里说出全支线最重的一句："我不是想让世界安静。我是想知道，如果我不敲钟，我还是不是我。"支线结尾他把一截捡来的断弦交给玩家——来历不明，是绝弦者招募者留下的（断弦峡谷篇的远线）。

### 敌人与生态

- **残忆失声者**（本区起登场）：走音钟辖区那条街的居民变的——还记得自己是谁，站在自家门口重复生前的一句话："钟……今天没响吗。"打他们时他们不扑声音，他们在找声音。战斗的难受感从这里开始升级。
- **蚀钟者（回声失声者变体）**：专啃钟的回声的残影，附在钟楼里让钟一口口走音——本章的精英怪，也是"缺"节拍的幕后。
- **钟鸟**：原野生态，学舌钟声；老练的钟鸟能把齐鸣学全。新守钟人最怕它——分不清哪声是钟、哪声是鸟，就是静默混进来的那一天。

### 声音生态

钟城的声音是人造的秩序：齐鸣、单钟的报时、铸钟坊的锤声、宿舍的更漏——每一声都有岗位。唯一的例外是无钟谷的绝对安静。与灰烬原野的"土地自己的声音"对照：第一区问"世界原本的声音"，第二区问"人造的声音算不算数"——答案写在洪钟身上：他听不见，但他守的声音是真的。

### 与其他地区的连接

- 西 · 旧驿道 → **灰烬原野**（来路）
- 东 · 钟原大道 → **碑林高原**（本章末开放，下一章细化）
- 北 · 无钟谷 → 静默渐浓，无路（首发封锁；谷的方向正对无声之境）
