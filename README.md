# 回声大陆 · Echo Continent: The Last Decade

世界是乐神唱出来的一首歌。纪元末，歌声如回声般衰减，「静默」降临，世界重开。你是唯一不被静默夺走声音的人——在第六纪元的最后十年，把这首歌重新唱下去。

*The world is a song sung by a sleeping god. At the end of every era the song fades like an echo, Silence falls, and the world begins again. You are the only one Silence cannot take — in the last ten years of the Sixth Era, it falls to you to sing the world back.*

一款 2D 平面大世界网页游戏。单机、本地存档、无限定卡池、无付费——世界观与系统设计见 [世界观设定集](docs/worldview-draft.md)。

## v0.1 · 序章「灰烬原野」

- **主线五拍**：残碑醒来（首次共鸣）→ 守碑村《守碑录》→ 半埋之城取钟舌（Boss：无我失声者）→ 回村敲钟、灰线后退 → 旧驿道遇送信人阿迟
- **探索**：纯正音符 3 枚（主线 1 + 探索 2）、支线 2 条、商店、随机遇敌
- **战斗**：回合制 +「声量」机制——技能越响，失声者扑得越狠；低鸣压声、道具与走位取舍
- **共鸣（抽卡）**：普通池常驻——余音之子 / 阿迟 / 弦外 / 莫弹；乐魂含本体共 7 份封顶，满溢出转回声碎片；无限定、无付费入口
- **操作**：WASD / 方向键移动，E 互动；触屏有虚拟摇杆
